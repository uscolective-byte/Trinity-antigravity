# Trinity Archív — Legacy Templates & Standalone Apps

Tento adresár obsahuje archivované frontend šablóny, starter projekty a standalone experimenty, ktoré boli pôvodne umiestnené v koreňovom adresári repozitára `Trinity-antigravity`.

## Dôvod konsolidácie:
- Vyčistenie a zjednotenie štruktúry hlavného stromu pre produkčný systém **Trinity v7.0.0 / Cloudflare**.
- Zachovanie plnej histórie a dostupnosti pre prípadné referencie alebo opätovné použitie.

## Zoznam archivovaných položiek:
- `chanfana-openapi-template/` — Chanfana OpenAPI šablóna
